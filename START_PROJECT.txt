================================================================================
                    PROJECT STARTUP GUIDE
================================================================================

PREREQUISITES
================================================================================
1. Node.js (v14 or higher) - Download from https://nodejs.org
2. Ollama - Download from https://ollama.ai
3. Git (optional) - For version control

Check if installed:
  node --version
  npm --version


STEP-BY-STEP STARTUP
================================================================================

STEP 1: INSTALL OLLAMA & MODEL
--------------------------------------------------------------------------------
1. Download and install Ollama from https://ollama.ai

2. Open terminal/command prompt and run:
   ollama pull llama3.2

3. Verify Ollama is running:
   curl http://localhost:11434
   
   Should return: "Ollama is running"


STEP 2: SETUP BACKEND
--------------------------------------------------------------------------------
1. Open terminal in project folder:
   cd c:\Users\hp\Desktop\ai_chatbot\backend

2. Install dependencies:
   npm install

3. Verify data files exist:
   - backend/data/agentData.json
   - backend/data/agentLoginData.json
   
   If missing, create empty arrays: []

4. Start backend server:
   npm start

5. You should see:
   "Indexed X agents, Y keywords"
   "Server is running on http://localhost:5000"

6. Test backend (open new terminal):
   curl http://localhost:5000
   
   Should return: "AI Travel Chatbot Backend is running."


STEP 3: SETUP FRONTEND
--------------------------------------------------------------------------------
1. Open NEW terminal in frontend folder:
   cd c:\Users\hp\Desktop\ai_chatbot\frontend

2. Install dependencies:
   npm install

3. Start frontend:
   npm start

4. Browser should automatically open: http://localhost:3000

5. If not, manually open: http://localhost:3000


STEP 4: TEST THE APPLICATION
--------------------------------------------------------------------------------
1. You should see the chat interface with:
   - Header: "Travel AI Bot (Streaming)"
   - Welcome message from bot
   - Input field at bottom

2. Try test queries:
   - "hello"
   - "agent@example.com" (if you have data)
   - "what is the email of John Doe" (if you have data)

3. Bot should respond with streaming text


TROUBLESHOOTING
================================================================================

PROBLEM: "Ollama is not running"
SOLUTION:
- Start Ollama application
- Or run: ollama serve
- Check: curl http://localhost:11434

PROBLEM: "Port 5000 already in use"
SOLUTION:
- Kill process on port 5000
- Or change port in backend/server.js:
  const PORT = 5001;

PROBLEM: "Port 3000 already in use"
SOLUTION:
- Kill process on port 3000
- Or when prompted, press 'Y' to use different port

PROBLEM: "Cannot find module"
SOLUTION:
- Delete node_modules folder
- Delete package-lock.json
- Run: npm install

PROBLEM: "No data found"
SOLUTION:
- Check backend/data/agentData.json has data
- Check backend/data/agentLoginData.json has data
- Restart backend server

PROBLEM: "CORS error"
SOLUTION:
- Make sure backend is running on port 5000
- Make sure frontend is running on port 3000
- Check browser console for exact error

PROBLEM: "LLM offline"
SOLUTION:
- Verify Ollama is running
- Check model is downloaded: ollama list
- Pull model again: ollama pull llama3.2


QUICK COMMANDS REFERENCE
================================================================================

START EVERYTHING:
1. Terminal 1: ollama serve
2. Terminal 2: cd backend && npm start
3. Terminal 3: cd frontend && npm start

STOP EVERYTHING:
- Press Ctrl+C in each terminal

RESTART BACKEND:
- Terminal 2: Ctrl+C, then npm start

RESTART FRONTEND:
- Terminal 3: Ctrl+C, then npm start


WINDOWS SPECIFIC COMMANDS
================================================================================

Check if port is in use:
  netstat -ano | findstr :5000
  netstat -ano | findstr :3000

Kill process by PID:
  taskkill /PID <PID> /F

Example:
  netstat -ano | findstr :5000
  (Shows PID, e.g., 12345)
  taskkill /PID 12345 /F

DEVELOPMENT WORKFLOW
================================================================================

Daily startup:
1. Start Ollama (if not auto-started)
2. cd backend && npm start
3. cd frontend && npm start
4. Open http://localhost:3000

Making changes:
- Backend changes: Restart backend (Ctrl+C, npm start)
- Frontend changes: Auto-reloads (no restart needed)
- Data changes: Restart backend
