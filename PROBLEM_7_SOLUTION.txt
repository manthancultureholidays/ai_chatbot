KEY FEATURES
================================================================================

1. Redis Cache
   - Stores search results (1 hour TTL)
   - Automatic expiration
   - Shared across servers
   - Fallback to in-memory if unavailable

2. SQLite Database
   - Persistent storage
   - Indexed queries
   - ACID transactions
   - No external dependencies

3. Smart Caching
   - Cache key: search:{query}
   - TTL: 3600 seconds (1 hour)
   - LRU eviction
   - Pattern invalidation

4. Graceful Degradation
   - Redis unavailable → In-memory cache
   - Database empty → Load from JSON
   - No downtime

TROUBLESHOOTING
================================================================================

Redis not running:
- System uses in-memory fallback
- No errors, just slower
- Install Redis for full benefits

Database locked:
- Close other connections
- Restart server
- Check file permissions

Out of memory:
- Increase Redis memory limit
- Enable LRU eviction
- Reduce TTL values
